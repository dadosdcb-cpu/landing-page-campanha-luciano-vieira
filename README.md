# Luciano Vieira — Deputado Federal 4545

Landing page oficial de campanha desenvolvida em HTML, CSS e JavaScript puro.

## Executar localmente

Use um servidor HTTP local (necessário para carregar as listas de candidatos):

```bash
python -m http.server 8080
```

Depois acesse `http://localhost:8080`.

## Publicação

O projeto é estático. Basta publicar todo o conteúdo da raiz em um servidor web.
